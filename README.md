# SCT_WD_3 Quiz Web App

## Description

This project is an interactive quiz web application developed as Task 3 for the SkillCraft Technology Web Development Internship.

## Features

- Multiple-choice questions
- Interactive quiz interface
- Instant answer selection
- Score calculation
- Correct and incorrect answer feedback
- Next question navigation
- Final score display
- Restart quiz option
- Responsive design
- Mobile-friendly layout

## Technologies Used

- HTML5
- CSS3
- JavaScript
